# Conversational interface

**Type:** entity
**First seen:** 2022 (conversational-interfaces-are-not-easy)
**Last updated:** 2026-04-12

## Summary
Conversational interfaces are any interfaces where interaction is mediated through natural language exchange: chatbots, voice assistants, LLM chat interfaces. Maaike argues that conversational interfaces are poorly suited to non-linear, generative tasks like writing — and that the field has been too slow to question whether the conversational metaphor is the right one for these new capabilities.

## How Maaike uses this concept
This is Maaike's home territory: she is a conversation designer who has spent years studying how conversational interfaces work and fail. Her analysis in the GenAI era focuses on the mismatch between the conversational form (linear, turn-based, context-constrained) and the tasks GenAI is used for (long-form writing, research synthesis, code generation). The conversational interface leads to cognitive load because it forces non-linear work into a linear medium.
