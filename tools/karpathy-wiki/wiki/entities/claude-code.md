## Summary
Claude Code is Anthropic's agentic AI coding tool. In Maaike's work it appears as both a tool she uses and a subject of analysis — an instance of agentic AI that she uses to argue for a shift from role-based to skill-based collaboration, and a demonstration of how building something is itself a form of specification.

## How Maaike uses this concept
Maaike observes that working with Claude Code changes the nature of creative and technical work: instead of delegating to specialists with fixed roles, you work with a system that can take on skills dynamically. This leads to her "building as specification" insight — the act of building something with Claude Code clarifies what you actually want in a way that verbal specification often doesn't. She also uses Claude Code to build her own digital garden, making her a practitioner-analyst of the tool.
