# Semantic information types

**Type:** concept
**First seen:** 2024 (context-engineering-lets-call-it-design)
**Last updated:** 2026-04-12

## Summary
Semantic information types are structured content building blocks with clear semantic labels — instructions, prerequisites, warnings, examples, context. Maaike argues these are the design vocabulary for context engineering: the typed blocks that make a context window coherent and useful. They come from existing information design traditions (information mapping, topic-based writing, instructional design).

## How Maaike uses this concept
Semantic information types are the practical answer to "what does context design actually look like?" A well-designed context window is not a wall of text — it is structured into typed blocks that the LLM can parse and use appropriately. This is what technical writers and instructional designers have always done with documentation. The vocabulary transfers directly.
