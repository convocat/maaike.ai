# Skill-based work

**Type:** concept
**First seen:** 2025 (from-role-to-skills-how-claude-code-desilos-the-future-of-work)
**Last updated:** 2026-04-12

## Summary
Skill-based work is Maaike's framing for a post-GenAI model of professional collaboration: instead of people in fixed roles (designer, developer, writer), work is organized around skills that can be dynamically assigned — to humans or AI. Claude Code leads to this model by enabling someone to take on skills (code, design, writing) dynamically without hiring role-based specialists.
