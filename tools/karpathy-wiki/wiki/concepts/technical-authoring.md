# Technical authoring

**Type:** concept
**First seen:** 2024 (context-engineering-lets-call-it-design)
**Last updated:** 2026-04-12

## Summary
Technical authoring is the professional practice of creating structured, accurate, user-focused documentation for technical products and systems. Maaike cites it as one of the existing professional practices whose work maps directly onto what is now called context engineering — technical authors have been designing structured information for consumption by systems (documentation, help systems, manuals) for decades.
