# Maturity system

**Type:** concept
**First seen:** 2024 (garden-as-metaphor)
**Last updated:** 2026-04-12

## Summary
The maturity system is Maaike's structural mechanism for making thinking-in-public visible in her digital garden: four stages (draft, developing, solid, complete) indicate the epistemic state of each piece of content. It is an implementation of the garden metaphor's core insight — ideas grow over time — made structurally visible in the interface.
