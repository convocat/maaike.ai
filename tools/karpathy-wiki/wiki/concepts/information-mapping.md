# Information mapping

**Type:** concept
**First seen:** 2024 (context-engineering-lets-call-it-design)
**Last updated:** 2026-04-12

## Summary
Information mapping is a structured writing methodology that organizes content into typed, labeled blocks (procedures, concepts, facts) for clarity and reuse. Maaike cites it as a source discipline for context design — the typed block structure of information mapping maps directly onto how context windows should be structured.
