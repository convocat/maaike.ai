# Information architecture

**Type:** concept
**First seen:** 2024 (context-engineering-lets-call-it-design)
**Last updated:** 2026-04-12

## Summary
Information architecture is the structural design of information environments: organizing, labeling, and structuring content so it is findable, usable, and meaningful. Maaike argues that context design — her reframing of context engineering — is an instance of information architecture applied to LLM context windows. The skills and methods of information architecture translate directly into what is now being called prompt engineering.

## How Maaike uses this concept
Information architecture is one of the existing disciplines Maaike points to when arguing that GenAI doesn't need new expertise — it needs to recognize the expertise it already has in adjacent fields. The structural logic of information architecture (typed content, hierarchies, relationships, labels) maps onto context window design. Maaike uses this to argue that information architects belong in the GenAI conversation.
