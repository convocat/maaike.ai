# System prompt

**Type:** concept
**First seen:** 2024 (context-engineering-lets-call-it-design)
**Last updated:** 2026-04-12

## Summary
The system prompt is the instruction set passed to an LLM before the user turn, defining its behavior, constraints, persona, and context. In Maaike's framework it is an instance of context design — a structured information artifact that shapes how the model behaves. Designing a good system prompt is information architecture work, not engineering work.
