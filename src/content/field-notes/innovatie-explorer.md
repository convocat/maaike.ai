## Goal

Build a GraphRAG explorer over the Dutch government digital-innovation landscape, and use the build to surface practical patterns for hybrid multi-agent systems on the Claude Agent SDK, especially around cost engineering and grounded retrieval. The code lives in [convocat/innovation-explorer](https://github.com/convocat/innovation-explorer) (private); this hub is the public learning log.
