A comparison mockup for the [[index card]] used on collection grids and the homepage stream. The current variant shows only the post's `description` frontmatter field. The proposed variant adds a three-line clamped excerpt pulled from the post body, with a "Read more" link below.

The mockup renders both side by side in the same grid layout so the visual difference reads at a glance: how much vertical space the excerpt adds, whether the read-more affordance is necessary when the title already links to the post, and how the clamp interacts with cards that have short bodies.

The page predates the May 2026 earth-tone palette migration, so the read-more link still uses the retired hot-pink accent. Treat the layout question as the live one, not the color.
