A pattern study for surfacing status on a list of items: pending review, done, skipped. The mockup compares three approaches side by side, each rendered as a column of five cards with the same sample content.

Variant A uses a thick left border in the status color, flush against the card. Variant B uses a tinted card background paired with a thin status strip. Variant C uses a small colored dot in the corner. The badges (Pending, Done, Skipped) remain consistent across all three so only the ambient signal changes.

The pattern is intended for the dashboards Maaike uses to triage pre-enriched weblinks and other batch-review queues. The same approach could carry to the [[index card]] strip if a status-by-collection signal is ever needed there.
