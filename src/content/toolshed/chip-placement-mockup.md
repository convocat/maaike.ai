A layout study for the Wander chips in the [[chat panel]]. The current pattern places suggested prompts inline inside the message stream. The mockup compares that with three alternatives: a "Wander" button in the toolbar that opens a popover, a horizontal band of chips above the input composer, and a vertical side rail.

Each variant is rendered in its own card with the same three example chips so the structural difference reads cleanly. The mockup includes notes on the trade-offs: how many clicks to access, whether chips compete with the message thread for attention, and how the chip placement scales when the chat grows long.

The decision recorded on the page itself: keep chips inline, drop the model handoff variant. The mockup is preserved here as the reasoning trail.
