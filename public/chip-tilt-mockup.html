Chip tilt — technically feasible variants

Same three chip texts in each row. Hover any chip to see the upright + lift state we already have. Below each variant: notes on what's actually happening and what it costs.

A. Current (subtle: 1.5° / 1.2° / 0.6°)

What's live now. The whole chip rotates including its text, but the rotation is so small you may not notice it.

B. Stronger (4° / −3° / 2°)

Same approach, just with bigger angles. Reads as deliberately tilted rather than "was the printer skewed?". Cheap, no markup change.

C. Bold (7° / −5° / 4°)

Theatrical. Reads as scattered notes, sticker-on-fridge. Risks looking sloppy if the chip text is long and wraps.

D. Upright chip, text tilted inside

The chip border stays straight, the text inside rotates a few degrees. Reads as "handwritten label on a printed badge". Requires wrapping each chip's text in a <span>.

E. Both tilted, different angles (compound wobble)

Chip is rotated, text is rotated relative to the chip. The text ends up slightly off-axis even relative to the chip's tilt. Most random-looking. Same span wrapping as D.

F. Per-letter wobble (handwritten feel)

Each letter individually rotated. Reads as hand-lettering. Significantly more DOM (one span per letter) and accessibility-fragile, and breaks naturally with text-to-speech and selection. Including for completeness, but I'd recommend against shipping this.

My pick: B for a quiet upgrade (no markup change), or E if you want it to feel more deliberately scattered.
