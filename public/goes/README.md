# The /goes downloads folder

Drop any file you want people to download into **this folder**, then run
`publish.bat`. It will appear automatically on https://www.maaike.ai/goes —
with its name, file-type icon and size. No code editing needed.

To remove a download, delete the file from this folder and publish again.

To change the page title, intro text, or the Google Drive button link,
edit `src/pages/goes.astro` (the few clearly-marked lines at the top).

This README and any file starting with a dot (like `.gitkeep`) are ignored and
never shown as downloads.
